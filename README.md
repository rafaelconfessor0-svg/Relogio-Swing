# ⏰ Relógio Swing - Java

## 📖 Sobre o projeto

Este projeto foi desenvolvido em Java utilizando Swing para exibir a data e a hora atuais do sistema em uma interface gráfica.

O objetivo é demonstrar a utilização das classes de manipulação de data e hora da linguagem Java, juntamente com eventos e componentes gráficos do Swing.

## 🚀 Tecnologias utilizadas

- Java
- Java Swing
- Maven
- NetBeans

## 🎯 Objetivo

Praticar:

- Programação Orientada a Objetos (POO)
- Desenvolvimento de interfaces gráficas com Swing
- Manipulação de data e hora
- Eventos de componentes
- Organização de projetos Java

## ▶️ Como executar

1. Clone este repositório.
2. Abra o projeto no NetBeans.
3. Execute a aplicação.
